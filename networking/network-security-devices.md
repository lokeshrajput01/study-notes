## What I understood

**Firewall:**
It is a security system that monitors and controls network traffic according to security rules.
It decides which traffic should be pass or which traffic should be block.
It placed at boundary between organisations internal network and internet.
It is also placed between internal network segments.
And the host based firewall directly runs on individual computers.

**Proxy:**
It acts as an intermediary between the users computer and destination server.
Instead of our computer communicating to th website it sends request through proxy server.
It purpose is to manage,monitor,filter,forward users request to the server.
A forward proxy is placed between the companies internal user and the internet.
A reverse proxy is placed in front of web servers to protect them from direct internet exposure.

**IDS:**
IDS(intrusion detection system) it is a security system that monitors network traffic or system activity and generate alerts.
It detect suspicious activities, generate security alerts and help soc teams to investigate potential attacks.
The network ids (NIDS) is commonly placed at strategic points in network to monitor traffic. And the host IDS (HIDS) is directly monitors activity on a individual comp and server.

**IPS:**
IPS(intrusion prevention system) is a security system that monitors network traffic detects suspicious activity and it can automatically block or prevent it.
It detect malicious activity, block suspicious traffic and prevent certain network based attack.
A network IPS is deploy iline,means network traffic pass through it.

**WAF:**
WAF(web application firewall) it is a security system that monitors and filters HTTP/HTTPS traffic going tn web application.
Protect web applications,detect and block malicious web requests.and help to defend against attack.
WAF placed in front of web application between the user and web server.
